      Help

      Use the Console

      Play and Control Media
      1. Open Overview.
      2. Select Play Presentation to start the presentation.
      3. Select Pause to hold the current frame.
      4. Select Resume to continue.
      5. Select Play Locally to use the playhead on this player.
      6. Drag the playhead to a new position in the local MP4.
      7. During group playback, drag the playhead on any included player to start the group at the new position.

      The playhead reads the native player once per second. Group Pause and Resume require all included players online.

      Set the Group
      1. Open Settings.
      2. In Playback Mode & PTP, select Leader, Follower or Standalone.
      3. Use the same group name and PTP domain on each group player.
      4. Select Save Mode & PTP.
      5. On the leader, open Overview.
      6. In Group Membership, select an available follower.
      7. Select Add Player.

      Prepare the follower’s card and peer credentials before you add it.

      Upload and Distribute a Clip
      1. Open Lower Layer Media Library on the leader.
      2. Use one MP4 for each group member. For example, use Welcome_A.mp4.
      3. Select the MP4 files.
      4. Select Upload.
      5. Select Distribute on the saved version.
      6. Wait for all group members to finish.
      7. Select Play Group.
      Identify a Player and Check its Status
      1. Select IDENT to show player and configuration details on its screen for 10 seconds.
      2. Select IDENT again to close it.
      3. To change the startup display, open Settings. In Startup, set Show IDENT on Boot and select Save Startup.
      4. Select Test Pattern to show local colour bars. Select it again to return to the current output.
      5. Read Device Status for local metrics and the HDMI screen ID.
      6. Select Edit Layout to arrange the player previews for the group.
      Set the Display and Clock
      1. Select Power On or Standby in the top bar.
      2. Read TV On, TV Off or TV Unknown after the display responds.
      3. Select Snapshot to see the player output.
      4. Open Settings to set the clock or schedule.
      5. Select Use This Computer’s Time to copy your computer’s time to the player.
      6. In Clock & Schedule, select or clear Enable Display Schedule.
      7. Select Save Schedule.

      The saved times use the Sydney time zone. The schedule controls screen power. Playback continues in standby.

      A follower uses the leader’s display schedule during group playback.

      Set HDMI, Audio and Network Time
      1. Open Settings.
      2. Select an output resolution in HDMI & Audio.
      3. Select an angle in Output Rotation.
      4. Select HDMI Audio to enable audio on this player.
      5. Set the volume or select Mute.
      6. Select Save HDMI & Audio.
      7. In Network Time, enter the NTP server to use.
      8. Select Save NTP.

      A resolution or rotation change restarts the player. All players can play audio. Select the audio players in Group Membership.

      Set Sources, Layers and Lighting
      1. Open Sources & Layers.
      2. Read the current source under Lower Layer.
      3. Select Play Presentation or choose an MP4 from Lower Layer Media Library.
      4. Select SRT Feed or Webpage.
      5. Enter the URL. Select Play Source.
      6. The player opens the last saved source at startup.
      7. On a follower, select Follow Group to return to group playback.
      8. Set the window position and size. Select Apply Window.
      9. In Upper Layer, enter the HTML5 overlay URL.
      10. Select Apply Overlay.
      11. Open Lighting to set the Art-Net or sACN input.
      Install an App Update
      1. Open Updates.
      2. Stage a signed file or fetch the package from GitHub.
      3. Check the staged version.
      4. Select Install and Restart.
      5. Wait for the player to start. Check the running version.

      API Help

      Connect to a Player
      1. Use HTTPS on port 8080.
      2. Trust the player’s public clock-cert.pem certificate.
      3. Use HTTP Basic authentication with the console credentials.
      4. Use /api/v1 before each endpoint path.
      5. Include X-SyncPlayer-Request: control in each request that changes a setting or starts an action.
      6. Use Content-Type: application/json when you send JSON.
      Read Player Status

      Use the player’s IP address in the request. This example uses Player A. Enter the console password when prompted.

      curl.exe --cacert clock-cert.pem --user SyncPlayer https://192.168.1.11:8080/api/v1/status

      Read the native object for the role, playback state, software version and HDMI power status.

      Send a Power Request
      1. Save {"power":"on"} to power.json.
      2. Send this request from the directory with power.json.
      3. Wait five seconds. Read player status to check the HDMI power report.
      curl.exe --cacert clock-cert.pem --user SyncPlayer -H "X-SyncPlayer-Request: control" -H "Content-Type: application/json" --data-binary "@power.json" https://192.168.1.11:8080/api/v1/display-power
      Common Requests
      GET /status
      Read player status.
      GET /playback
      Read the playhead position in milliseconds.
      GET /clock
      Read the clock and time zone.
      POST /play
      Send {"id":"presentation"} to play the presentation.
      POST /pause, /resume or /stop
      Send {}.
      POST /seek
      Send {"positionMs":30000} to move a local MP4 to 30 seconds.
      PUT /group/members/B
      Send {"included":true} to add provisioned Player B.
      PUT /group/audio/B
      Send {"enabled":true} to enable HDMI audio on Player B.
      PUT /settings
      Send {"scheduleenabled":true,"on":"07:00","off":"21:00"} to set the display schedule.
      POST /snapshot
      Send {}. Save the response as a JPEG file.
      PUT /settings
      Send {"identonboot":false} for a black screen until playback starts at the next boot.
      POST /ident
      Send {} to show IDENT for 10 seconds, or send {"mode":"test-pattern"} to show local colour bars. Send {"seconds":0} to close either screen.
      GET /network
      Read the Ethernet mode, address, mask, gateway and DNS settings.
      GET /sources
      List saved SRT feeds, RTSP feeds and webpages. Send a saved ID to POST /source to start it.
      GET /updates
      Read the running version and GitHub source.
      Read the Response
      • Use the result after an HTTP 200 response.
      • For 202, wait for the task to finish. Read status again.
      • For 401, check the credentials.
      • For 403, check the control header.
      • For 409, read the error. Check the player state before you retry.
